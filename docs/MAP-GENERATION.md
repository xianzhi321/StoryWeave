# 一键生成世界地图 · v1.3.0

进入“世界 → 一键生成地图”，自动生成第一张预览。也可以从地图窗口中的“一键生成”或新建地图窗口进入。

1. 选择大陆与海洋、群岛、山地岛屿、超级大陆、内海、半岛或火山岛。
2. 选择“自然地形”或“国家分区”。修改设置后点击“按设置生成”；“换一个世界”会换用新的随机种子。
3. 预览满意后填写地图名称，点击“采用此地图”。默认把生成的城镇一并保存为可编辑地点，也可取消勾选只保存底图。
4. 点击地图标记，修改城镇名称、别名或说明，并关联世界事件、人物和章节。地图时间轴继续筛选已经创建的事件。

每部作品最多四张地图。生成预览不会修改已有地图或正文，采用时新增地图；重复点击保存不会创建重复记录。离开生成窗口会释放生成引擎。保存失败时保留预览，修复存储问题后可以重试。

## 可复现与存储

生成图为 1200 × 800 像素，约一万网格单元。使用固定的 Azgaar 引擎版本与参数；相同版本、模板、样式、种子产生相同地形与城镇。在相同 Chromium 环境验证了 PNG 字节一致；不同浏览器的字体或栅格化可能存在细微差别。

种子允许 1–40 位字母、数字、短横线或下划线。引擎版本、模板、样式、种子随地图和全库 JSON 备份保存，地图设置中可查看生成来源，或点击“按原始设置生成新地图”再次生成。上传另一张底图后清除旧的生成来源，避免误认为新图仍能由旧种子复现。

完全本地生成，不调用 AI、不需要 API 密钥。原始生成引擎的存储被替换为独立内存存储；不会清空或改写《叙境》的作品数据。离线适配去掉统计脚本、在线字体和引擎自身的 Service Worker，禁止引擎发起网络连接。网页端首次完整缓存后可以离线使用；直接打开本地 HTML 也可生成。Android 工程内置相同资源，但 Android 实机仍待验收。

## 本版边界

- 使用 Azgaar 官方 `v1.109` 标签的经典 JavaScript 引擎，源码内部版本为 `1.109.1`；这不是最新 Azgaar 全功能编辑器的嵌入。
- 海陆、高程、河流和国家分区保存为 PNG 底图。地点是独立可编辑数据，名称不烘焙到底图，因此改名不会遗留旧地名。
- 生成的国家名称记录在城镇说明中；国家边界目前是静态图片，不是可编辑势力多边形，也不会随故事日期演变。
- 默认保留 Azgaar 的地名原文。尚未提供自动中文命名、人物路线、原生 `.map` 导入、地形雕刻或 3D 地图。
- “一键生成地图”不等于自动生成小说正文或历史事件；事件仍由作者创建或审核 AI 候选后采纳。
- 真机内存、长时间创作、系统强杀和低剩余空间尚待测试。

## 开发与复现

上游：[Azgaar v1.109](https://github.com/Azgaar/Fantasy-Map-Generator/tree/v1.109)。许可证见 `web/vendor/azgaar/LICENSE`，来源及适配记录见 [THIRD-PARTY.md](THIRD-PARTY.md)。

从官方标签解压目录重建适配资源：

```powershell
python build_azgaar.py PATH_TO_EXTRACTED_UPSTREAM_TAG
python build_release_assets.py
node test_generator_core.cjs
node test_generator_browser.cjs
node test_offline_assets.cjs
```

`build_release_assets.py` 更新 PWA 离线清单、同步 Android 资源并逐文件校验 SHA-256。变更引擎后应同时升级缓存版本，再运行浏览器回归。
