# StoryWeave v1.9.11 · 全局 UI 与轻动效

本版基于 v1.9.10，不改变作品/章节保存、AI 接口、写作感知统计公式或资料结构。新增独立的 `web/ui-fluid.css` 与 `web/ui-fluid.js`，分别管理视觉与页面导航动效，便于单独回滚。

## 界面改动

- 书架：统一纸色背景、卡片轮廓、阴影和封面圆角。支持悬停轻抬起（仅鼠标）、触屏按压微缩放；书籍进入动画仅在真实页面切换时触发。
- 作品页：强化目录选中状态、章节操作的触控反馈，改善小屏间距。
- 导航：底部三页签在选中时显示短下划线和轻微图标位移，避免突兀的背景闪烁。
- 编辑器：保持正文静止，不给输入区域、光标和写作统计图增加循环动画；统一正文边框和阴影；在墨夜稿纸下保持深色顶栏。
- 弹窗、抽屉和通知：统一短促的入场反馈，取消背景实时模糊以减轻滚动与合成开销。
- 无障碍：系统开启“减少动态效果”后，关闭页面、按钮与弹窗动画；键盘焦点继续有明确外框。

## 设计约束与效率

- 只在 `render()` 检测到顶层页签变化时启动入场动效，同一视图重新渲染、输入文本和输入法组合不触发。
- CSS 仅使用 `transform`/`opacity` 作为关键帧属性，单次时长 170–290 ms；没有每帧 JS 动画循环、滚动监听或持续变形的图表。
- `ui-fluid.js` 不读取或写入正文、本机作品库、浏览器存储，也不接触 AI 功能。
- 原有 `writing-sense.css`、统计核心及界面保持可用。

## 测试和适配

`python test_fluid_ui.py`：Chromium 内联真实项目 JS/CSS，验证书架、弹窗、目录、人物页、章节编辑、只在跨页面时动画、320/360/390/768px 不横向溢出、墨夜顶栏、系统减少动画设置。使用模拟存储，不能代替 Android 真机测试。

`python build_release_assets.py`：同步 Web → Android assets 并校验每文件内容一致，刷新 PWA 离线资源清单。

尚未重新编译 APK；真实手机上的软键盘、长列表动画帧率及低端设备耗电量需要实机测试。
