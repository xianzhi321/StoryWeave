# StoryWeave v1.9.15 全局视觉统一

## 设计基准

保持写作第一，不用升级/打卡/复杂装饰替代真实编辑体验。对安卓真机深色截图里的不同界面割裂进行修正：背景、正文、控件、人物卡片、资料区和弹窗使用一套统一规则。

| Token | 浅纸 | 墨夜 | 用途 |
| --- | --- | --- | --- |
| `--swui-canvas` | `#f6f6f1` | `#202925` | 整体背景 |
| `--swui-surface` | `#fffefa` | `#26322b` | 卡片、弹窗 |
| `--swui-surface-2` | `#f0f3ed` | `#2d3c32` | 次级信息 |
| `--swui-ink` | `#28382f` | `#e7ece4` | 主要文字 |
| `--swui-muted` | `#67776d` | `#b2c0b5` | 次要文字 |
| `--swui-line` | `#dfe6dc` | `#39483f` | 边框 |
| `--swui-accent` | `#305c48` | `#b9dac4` | 选中、主按钮 |

## 已统一

- 书架和目录沿用 v1.9.12 低对比、浅纸卡片风格；墨夜模式延伸到目录、人物、世界标签页。
- 人物档案与关系区：统一行高、头像颜色、信息层级；人物认知旧版深蓝横幅变为中性次级卡片。
- 世界设定、年表/世界档案折叠栏：墨夜下不再出现亮白条。
- AI 写作协作：弹窗、任务卡片、选中态、输入表单、发送预览继承主题。
- 资料抽屉、技能工坊、通用模态、表单及常见旧版横幅统一主题。
- Android 系统栏桥接不再仅在正文使用墨夜，切换标签页时避免上下色彩割裂。
- 正文编辑器依旧采用 v1.9.14 简洁稿纸，不新增输入监控或动效。

## 技术与回归

- `web/ui-system.css` **必须在其它 CSS 之后** 引入，不应与原来的 `ui-atelier.css`、`ui-manuscript.css` 交换顺序。
- `web/ui-manuscript.js` 只调整系统栏主题判断，浏览器主题色也同步更新；不触碰正文、项目数据库、AI 模型。
- Web 离线缓存与 Android `assets` 同步新增样式，更新版本缓存键。
- 历史 UI 截图断言 `test_atelier_ui.py` 使用旧固定颜色值，因此会失配，新主题请以 `test_art_unification.py` 为准。
- 第三方嵌入的 Azgaar 地图编辑器有独立 CSS，不强行覆盖。
