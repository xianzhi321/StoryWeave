# 叙境 StoryWeave v1.9.8

本版重构本机保存、书架操作和 EPUB 解压。源码对照、验证范围与未完成事项见 [重构审计](docs/REFACTOR-AUDIT.md)。在 Windows 上执行 `pwsh -File verify_core.ps1` 可重跑语法检查和核心测试；`-RealIndexedDb` 需要本机回环连接，`-Format` 使用固定版本 Prettier。

Android 专注模式会隐藏系统状态栏和导航栏。需要临时查看时可从屏幕边缘滑动，点左上角退出专注后恢复系统栏。

默认书封与「松影」「雾岚」稿纸采用原创矢量插画。稿纸可在「设置 → 稿纸与版式」切换并预览。

书架顶部的放大镜用于查找作品。点「添加」可以新建作品或导入书稿。写作技能、全文搜索和设置位于顶栏的「⋯」。打开作品后，在目录点「添加」新建章节或分卷。人物页先显示人物名单，点「人物关系」展开关系图。

在「世界 → 地图 → 待关联事件 → 批量关联地点」，可以核对原记录、候选地点和所属地图。勾选唯一匹配，或手动选择同名候选，再保存关联。还没填写坐标的地点继续显示为待定位。

从地图里的「正文」打开章节后，点写作工具栏的「返回地图」可恢复事件、筛选、搜索和缩放。专注模式可在「工具」里找到这个入口。地点有坐标时，详情中的「查看地图位置」会回到画布并高亮地点。

在「世界 → 地图」可先查看画布和故事时间。切换「事件」可按故事日期浏览当前地图的记录。点事件定位并高亮详情，点「正文」跳到关联章节。「管理地图」内可生成或导入地图，「筛选与图层」内可按章节、人物或日期筛选。

书架上的「继续写」直接回到最近打开的章节，恢复上次的选区和滚动位置。点作品封面可进入目录。需要从多部作品中查找时，展开「查找作品」，按作品名、类型或分组筛选。

写作时点「资料」，可查人物、世界设定、地点和术语。选中文字后可点「查找选中文字」，也可用「正文提及」筛出本章用到的名称和别名。资料详情里的「定位正文提及」会选中首次出现的位置。专注模式从「工具 → 本章资料」进入。

点章节右侧的「⋯」可编辑蓝图与稿件状态、移动章节或移入回收站。点卷名可折叠分卷，点卷名旁的「＋」可在卷末新建章节。搜索会展开匹配结果，清除搜索后恢复本次打开应用时的折叠选择。

在「AI 写作协作 → 附带资料与技能」选择配方，可查看每项技能实际发送的规则数量，也可临时取消勾选。「查看将发送的内容」展示完整输入。「更多任务」收纳对白、自然表达、压缩和剧情推演。

在「文学技能工坊 → 审核待审技能」可预选待审技能，再由作者确认。「批量管理」可一键组合、检查并删除完全重复项，或预览合并。合并可生成待审稿，已审核且范围一致的技能也可以合并并替换原卡。

在编辑器发起 AI 润色后，打开「逐处采用改动」可勾选希望采纳的修改。保存时保留未选中的原文，并记录修改前的版本。

「工具 → 剧情审核」默认打开本章。可逐条查看原文，也可用「多选审核」采纳或忽略选中的候选记录。

在世界地图选择参与人物，再开启「人物足迹」。可查看当前地图上有事件记录的地点，按故事日期筛选，也可从事件打开关联章节。

「工具 → 本章地点」汇总本章关联事件和正文提及的地点。地图的地点详情可展开关联章节并打开正文。

编辑器的「工具 → 本章资料」可查看关联资料、人物和世界设定。资料列表可直接关联本章，详情页可跳到关联章节。

「目录管理 → 批量移动」可勾选章节，再选目标分卷和插入位置。「编辑卷」可调整卷的顺序。

从全文检索点开正文命中后，可用编辑器里的「上一处」「下一处」跨章查看，或点「全部结果」返回当前结果页。关闭后收起搜索导航。

在编辑器的「工具 → 写作书签」标记光标处，可选填名称。在「目录管理 → 写作书签」也能查看本书的书签并跳回正文。

「导入小说」可预览 TXT、Markdown 和 EPUB 的章目，按识别到的卷和章导入，也可仅分章或合并为一章。EPUB 有阅读目录时按书籍顺序导入。

书架作品菜单、目录管理和编辑器工具均可打开「导出书稿」。选择全书或分卷、是否仅导出定稿，以及 TXT 或 Markdown，确认章目后保存。

目录的「查找章节」集中提供关键词、分卷和稿件状态筛选。需要找正文时可勾选「同时查找正文」，返回目录时保留这部作品的筛选。回收站恢复时优先按原相邻章节定位。

「写作技能 → 批量管理」可勾选技能后一次审核、组合成配方，或将规则和方法合并成一张待审新卡。蒸馏结果页可直接批量审核本次候选，证据失效的候选会继续待审。合并保留原卡与来源记录。

可按审核状态和关键词筛选技能，批量勾选只新增当前可见的待审卡。重复项按组勾选后删除，合并后可直接编辑新卡。

「检查重复技能」会预览内容和来源证据相同的技能。确认后保留优先已审核的技能，把版本历史、已有配方及分析任务引用接到保留项。

「设置 → 备份与迁移 → 导入备份」先显示备份时间、作品、章节与资料数量。默认追加新作品和资料，同 ID 的作品保留本机版本，本机模型配置也会保留。有冲突的章节或资料 ID 会拦截追加。

需要按备份还原整个书架时，选择「整库恢复」，可先导出当前备份，再单独勾选确认。两种模式均在本机写入成功后才更新书架。

## v1.7.8 蒸馏与版本恢复

分段蒸馏使用 DeepSeek 官方接口时，分析请求会关闭思考模式并要求 JSON 输出。已有任务可打开并从未完成的区段继续。

「写作工具 → 历史版本」可按段对照修改，也可查看当前全文和旧版全文。恢复前有二次确认。恢复的正文、标题与原稿快照一起写入。

## v1.7.7 DeepSeek 接入

「设置 → 模型连接」支持一键填入 DeepSeek 官方地址。粘贴 API Key 时会清理常见不可见字符、外层引号和复制进来的 Bearer 前缀。拉取、测试和保存共用这套校验。实际服务商拒绝鉴权时会显示 HTTP 状态。

拉取结果同时展示模型名称和模型 ID。DeepSeek 官方列表返回推荐模型时，可在模型栏为空或只填了服务商名时直接选中。测试使用固定短提示，并临时关闭官方 DeepSeek 的思考模式。

## v1.7.6 专注写作

专注模式使用单行顶栏。左侧退出，中间展开或收起章节标题，右侧打开写作工具。标题编辑框默认折叠，跳章、稿纸设置与 AI 协作收在工具面板。

在「设置 → 写作辅助 → 专注顶栏章名」可选单行章名或只显示「章节」。展开标题后可按回车回到正文，返回键或 Esc 会先收起标题。快捷标点只在正文获得焦点时显示。

## v1.7.5 云端模型连接

在「设置 → 模型连接 → 云端 AI」填写 OpenAI 兼容 API 地址和密钥，点击「拉取模型」，筛选并选择模型 ID，然后点击「测试连接」和「保存云端配置」。也可手填模型 ID。列表和写作请求在 Android 使用原生网络，网页版需要接口允许跨域访问。

API Key 按规范化的 API 地址长期保存在本机，可切换为仅会话使用，也可单独清除。Android 版使用 Android Keystore 加密，网页版使用当前浏览器的站点存储。作品备份仅保存接口地址和模型 ID。旧版会话密钥若已随应用关闭而清空，需重新填入一次。

## v1.7.4 蒸馏效率

「写作技能 → 提炼」可选全书分段或开篇研究，并指定综合技法、节奏结构、人物对白或场景视角。开篇研究取最多三个识别到的章首片段，无明确章名时使用一个开篇片段。全书分段默认取三个区段，可在「调整取样量」扩展。本机模型按可用上下文限制取样长度。

同一本参考书、相同取样范围、研究方向和模型配置可打开已有进度或结果，也可主动重跑。失败续跑保留已核验区段。结果按具体技巧聚合，优先显示有多个区段证据的候选，可从任务直接进入审核。

## v1.7.3 稿纸与技能工坊

在「设置 → 稿纸与版式」可实时预览稿纸、字号、行距和写作背景。背景提供纯色、松影、雾岚及本机 JPG、PNG、WebP 图片。点「应用」后，正文、专注模式和阅读预览共用背景。背景图片保存在当前设备的偏好设置中。

「写作技能 → 导入参考书籍」在空书架也可使用。新参考书与分析任务保存在技能工坊中，切换或删除创作作品不会移除它们。此前导入的参考书仍按原作品显示。深度蒸馏可展开核对取样原文，更改范围后需再次确认。

## v1.7.2 章节导航与排序

打开作品后，在「目录 → 查找章节」可按章名、卷名、章序号或蓝图查找，并与稿件状态筛选一起使用。在编辑器中可用「工具 → 跳转章节」查找并打开当前作品的任意章节。

在「目录 → 目录管理」点章节旁的「排序」，选择目标分卷及插入位置。同卷、跨卷和未分卷均可调整。全文导出和按章查看的资料采用新顺序，既有资料链接仍指向原章。

## v1.7.1 作品管理

长按书架封面或点「⋯」可查看、编辑、分组、置顶、导出和删除作品。支持的设备可打开系统分享面板。桌面浏览器可用右键。删除时先在应用内确认，存储成功后才移除书籍。参考书籍在技能工坊也有独立删除入口，已保存的技能保留。

## v1.7.0 设置与回收站

书架右上角「设置」按稿纸与版式、写作辅助、书架外观、AI 写作入口、模型连接、备份与迁移分组。编辑器「工具 → 全部设置」也可打开。字号、行距、字体、边距、稿纸横线与写作辅助独立保存于本机。

可选的 AI 快捷入口默认关闭。启用后，空章显示「AI 开头」，已有正文显示「AI 续写」，专注模式也可使用。可先填写人物、关键词或构思，核对提示词与发送内容，再生成候选。普通 AI 协作仍可独立打开。

在「目录 → 目录管理」删除章节会移入可恢复的回收站，正文、历史和专属记录随之保存。世界事件与伏笔本身保留，章节关联解除。恢复时尝试接回仍有效、没有重新绑定的引用。人物认知以本章为生效点时，需先调整引用。回收站随全库备份导出。

## v1.6.0 书架与写作体验

书架保留作品统计、封面、新建和导入。点封面进入该作品的目录，页签只有「目录、人物、世界」。点章节打开编辑器。技能工坊从书架的「写作技能」统计卡进入。

目录默认以紧凑行显示标题、状态和字数。展开「目录管理」可筛选、显示摘要、新建分卷、调整归属和设定每日目标。目录的「继续写」跳到最近编辑的章节，恢复光标与正文滚动位置。位置记录保存在当前设备。

「写作 → 工具 → 稿纸与字号」可选米纸、墨夜或随系统。夜间稿纸适用于正文、专注页和相关写作面板。「快捷复制」可单独复制标题、正文，或合并复制。

「排版预览」可选清理行尾空白、压缩连续空行和两格缩进。确认后才应用到本章，并将原稿保存在历史版本。它适用于纯文本小说正文。

## v1.5.0 手机写作与 AI 工坊

写作页以正文为主，工具面板按写作、章节资料、显示与文件分组。手机专注模式根据可见高度调整编辑区，支持快捷标点和引号、书名号包裹选区。

AI 协作内置续写、润色、打磨对话、自然表达、压缩、审稿和后续推演。可查看完整的发送文本、按作品保存任务提示词、选择本次附带的设定与资料。正文候选由作者预览、编辑和采用。采用选段改写会保存原稿版本，原稿发生变化时需重新生成。

世界页提供六项结构化背景与术语表，术语可写定义、别名和用法。章节概览按卷展示稿件状态、目标与字数，可新建卷、调整章节归属并导出含卷名的全文。旧章默认列在未分卷。移动章节会改变全书顺序。

## v1.4.0 写作工作台

进入「写作」可直接写正文。上方「作品与章节」可展开切换章节或查看每日目标。点「专注模式」隐藏工作台面板，保留正文、保存状态与字数。通过工具栏或 Esc 退出。「显示」可调整字号与行距，偏好保存在当前设备。

「世界 → 作品知识库」可管理设定、考据、灵感和写作要求，支持 TXT、Markdown、来源、标签检索与章节关联。「写作 → 本章资料」可按关联筛选。知识库按作品保存，并随全库 JSON 备份。

「写作 → 蓝图」可记录本章目标、冲突和情节节点，并标记待审或定稿。定稿保存快照，修改标题或正文后显示待复审。「创作进度」按状态筛选章节并显示全书字数与每日目标。普通 AI 写作协作可选带本章蓝图或一条关联资料的预览节选，默认不附带。

功能参考 [Hammer Editor](https://github.com/Darkrock-Studios/hammer-editor)、[书童 Pagekin](https://github.com/EthanYoQ/Pagekin) 和 [易创](https://github.com/yilujian/easy-writing)。

## v1.1.1 更新

本版打磨 AI 连续性审查。勾选章节后可以展开查看实际发送的片段和资料，本机模式按完整请求长度控制上下文。切换章节选择后需要重新勾选发送授权。

审查结果只接受本次发送片段中的证据。正文或作品在请求期间发生变化时会提示重新审查。重复请求的相同意见会去重，过期意见可以忽略，历史审查记录随全库备份完整保留。

**定位：以小说正文创作为中心的跨平台写作工作台。** 本版优先扩展长篇连续性管理，避免把写作工具做成只有聊天框的 Agent 面板。

## v1.1.0 新增

- **人物 → 人物成长轨迹**记录角色在每章结束时的性格、目标、信念、心理状态和变化原因。后续章节沿用最近一次状态。角色视角的 AI 上下文会读取该章的性格、目标和公开关系。
- **写作 → 场景管理**沿用原有场景卡，可填写地点、故事时间、关联事件，并独立调整场景顺序和人物出场顺序。
- **人物 → 按章节查看关系图**按章还原关系与信任值，支持聚焦某个人物。
- **世界 → 全书设定冲突扫描**在本机统一核对人物认知、伏笔、关系、事件编年及场景关联，可从报告跳转到章节。语义审查另从报告进入 AI 深度审查，选择章节和发送范围。
- **写作 → AI 整理本章剧情**分段提取事件、行动与关系变化。发送前可查看确切的正文范围、人物姓名和公开关系编号。每条候选需附原文，作者采纳后才进入对应档案。世界事件的日期由作者在编年中补填。

v1.0.0 备份可直接导入。全库 JSON 备份现在也包括人物成长和剧情归档，场景卡中的新字段与原来的场景资料一起保存。

## v1.0.0 功能

1. **章节级伏笔关联**：每条伏笔可以跨章节标记埋设、发展、提及和回收；可从关联跳转到正文；保留旧版单章节数据兼容。
2. **人物关系演变**：记录每章关系变化、信任值、双方态度和变化原因；可以按章节还原关系状态。
3. **世界事件编年**：记录故事内日期、章节、地点、人物、起因和结果；识别章节顺序与故事日期的可疑倒置，允许标记倒叙。
4. **连续性审查**：规则审查 + 作者主动确认的 AI 审查；AI 意见必须附逐字原文证据，未经作者确认不改动正式内容。

## AI 与本地模型

- 云端 AI：使用设置中配置的 OpenAI 兼容服务。
- 手机本地 AI：通过同一台 Android 设备上的 IRIDIS API 调用。
- 不开发独立内置 GGUF / LiteRT-LM 推理引擎。
- 本机模式不会自动回退到云端；AI 审查在发送所选章节前需要单独勾选授权并再次确认。

## 当前限制

- 未完成 Android 真机安装与 WebView 文件选择器验收。
- 未完成手机—电脑实时同步；当前仍以本机 IndexedDB / Android WebView 存储为主。
- Azgaar 地图双向同步未开发。
- 章节间复杂叙事（多层倒叙、平行时间线）的自动判断仍需要作者复核；规则检查是提示，不是裁决。
- AI 连续性审查只能检查所选章节与有限资料，不代表对整本书做了完整证明。
