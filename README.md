# 叙境 · StoryWeave

跨平台小说写作与创作资料管理项目。

> **仓库状态：初始化中。** 当前 GitHub 仓库已经建立项目说明与安全忽略规则，但 **v1.9.17 的完整源码尚未完成传输**。请不要将此仓库视为可构建版本或正式发布。

## 当前开发基线

- **版本**：v1.9.17 native-tablet audit（本地源码包）。
- **Android**：原生平板入口采用 Java + Android View；旧版手机与数据迁移功能仍有 WebView 依赖。
- **写作功能**：原生平板书架、章节目录、正文编辑、自动保存、本地备份导入导出。
- **未迁移功能**：完整人物关系、地图与 AI 工坊等仍未在平板原生端实现。
- **验证状态**：源码静态检查和有限 JVM 测试通过；尚未编译 Android APK，也未通过真机验收。

## 计划中的源码目录

```text
android/      Android 原生应用及过渡功能
web/          既有网页功能与兼容资源
desktop/      桌面端实验代码
docs/         架构与迁移说明
tests/        浏览器、Node 与 JVM 测试脚本
```

## 数据安全

任何版本迁移前请先在原版应用导出完整 JSON 备份。原生数据仓库与原版 IndexedDB **不会自动同步**；原生备份导入目前为替换导入，不是合并。

安全与已知限制请参阅 [v1.9.17 原生平板审计](docs/NATIVE_TABLET_AUDIT.md)。

## 许可和第三方资源

项目部分依赖 Azgaar 地图与 Leaflet 等第三方资源；首次提交完整源码时须保留各上游 LICENSE 与版权声明。不要上传 API 密钥、密钥库、签名材料和个人作品数据。
